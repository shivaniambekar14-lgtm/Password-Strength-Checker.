Password Strength Checker Using Python

A Python-based Cryptography and Network Security (CNS) mini project that estimates password strength using length, character variety, and a small list of common passwords.


Objectives


Classify sample passwords as Weak, Medium, or Strong.

Check password length, uppercase and lowercase letters, digits, and special characters.

Provide suggestions to improve password security.

Demonstrate basic password-security awareness through a graphical interface.


Features


GUI built with Python Tkinter

Show/hide password field

Strength estimate and improvement suggestions

Checks a small list of common example passwords

Does not save or transmit entered passwords


Technologies


Python 3

Tkinter

Regular expressions (re)


Requirements

Python 3.9 or later. Tkinter is included with most standard Python installations. No third-party packages are required.


Run the project


Download or clone this repository.

Open a terminal in the project folder.

Run:


python main.py

On some systems, use python3 main.py.


How it works

The program checks password length and whether it includes uppercase letters, lowercase letters, numbers, and special characters. It gives a simplified score, then displays a strength estimate and suggestions. A small built-in list flags a few common passwords.


Limitations and safety

This is an educational demonstration, not a professional password-auditing tool. Its simplified score cannot guarantee security, and its common-password list is not comprehensive. Do not enter real account passwords into a classroom demo or shared device.
